Maxence Poirier-Joanette, Adrien Badet, Alexandre Éthier, Bérince Hounsouvo

Hypothèses

  1. Comment évoluent les populations de fringillidés boréaux (4 espèces) dans le temps (1996-2025) ; tendances temporelles sur 30 ans de suivi
    1. Est-ce que la proportion de jeunes de l’année (indice de succès reproducteur) évolue dans le temps ?
    2. Comment évolue la condition corporelle des différentes classes au cours du temps ?
  2. Qu’est-ce qui explique les irruptions des différentes espèces de fringillidés ?
    1. Est-ce que la proportion de jeunes de l’année (indice de succès reproducteur) est corrélée avec l’abondance annuelle?
    2. Est-ce que la condition corporelle est corrélée à l’abondance annuelle ?

Irruption

abond_irruption <- abond %>%
  group_by(Espece) %>% # Par espèce
  mutate( #On créé 6 nouvelles colonnes
    N = abond_std, #valeur de N (mean count)
    P  = mean(abond_std), # valeur de P (valeur prédite)
    numerateur   = N-P, 
    sigma       = sd(numerateur),
    standardized_deviate           = numerateur / sigma,
    seuil = abs(min(standardized_deviate)),
    irruption   = standardized_deviate > seuil
  ) %>%
  ungroup()
